# Android Project 2 - WishList

Submitted by: **Christian King**

**WishList** is a small wishlist app that helps the user keep track of things they want to buy.

Time spent: **3** hours spent in total

## Required Features

- [x] **User can add an item to their wishlist**
- [x] **User can see their list of items based on previously inputted items**

## Optional Features

- [x] Wishlist app is customized with a simple purple theme
- [x] User can delete an item by long pressing it
- [x] User can open an item's URL by clicking on it

## Video Walkthrough

Not recorded yet.

## Notes

The main challenge was figuring out how to update the list after an item is added and how to use an intent to open a web link. I kept the list code simple instead of using a RecyclerView because I am still learning Android layouts.
